# BRC 2026 — offline map

Built app output only. Open `index.html` on a phone over https, then
**Share → Add to Home Screen**. The service worker caches everything on first
load, so it works with no cell service afterwards.

Live at <https://narsino.github.io/brc-map/>.

City geometry: official Burning Man GIS data
(<https://github.com/burningmantech/innovate-GIS-data>).
Not affiliated with Burning Man Project.
